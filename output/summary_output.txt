* **JavaScript and Development Environment**
  * JavaScript's primary purpose is to develop android application, allowing developers to manipulate content and behavior directly within the user's web browser.
  * JavaScript can dynamically update web page elements, validate form inputs, and respond to user interactions.

* **Note-Taking and Searchable Notes**
  * The author needed a better way to take searchable notes, with requirements including handwritten notes, normal handwriting, searchability, and clarity for future recall.
  * The author considered using Evernote, but found its formatting to be imperfect and requiring manual correction.
  * The author discovered a solution using Cloud AI, which could convert handwritten notes to text files.

* **Thermodynamic Cycles**
  * A cycle is uncompleted when a system undergoes a number of processes and returns to its original conditions.
  * A cycle must be completed to obtain continuous work, and consists of heat addition, work done, heat rejection, and compression.
  * An ideal cycle is one in which expansion and compression take place adiabatically and reversibly (isentropically).
  * Reversible and irreversible processes are defined based on whether a system can retain its original conditions along the same path in the reverse direction.

* **Computer Networking Components**
  * Network Interface Cards (NICs) are hardware components that allow devices to connect to a network.
  * Cables or wireless signals are the mediums through which data is transmitted between devices.
  * Routers forward data packets between different networks and serve as the connection point between a local network and the internet.
  * Switches connect multiple devices within a local network, allowing them to communicate with each other efficiently.
